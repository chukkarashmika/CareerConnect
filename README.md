# 🚀 CareerConnect
### Your Gateway to Dream Careers

CareerConnect is a modern frontend Job Board Application designed to help students and freshers explore job opportunities with ease. Users can search jobs, filter opportunities by location, save jobs for later, and view detailed job information through an interactive and user-friendly interface.

---

## 🌐 Live Demo

🔗 https://chukkarashmika.github.io/CareerConnect/

---

## 📌 Features

✅ Browse available job opportunities

✅ Search jobs by title, company, or location

✅ Filter jobs based on location

✅ View detailed job descriptions in a popup modal

✅ Save favorite jobs using Local Storage

✅ Responsive and user-friendly design

✅ Fast and lightweight frontend application
